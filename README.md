# discogs-genre-classifier

Ready to run music genre classifier using [essentia](https://essentia.upf.edu/essentia_python_tutorial.html) with tensorflow

## Requirements

- [uv](https://docs.astral.sh)
- [git-lfs](https://git-lfs.com/)

This setup has been tested with MacOS 15.
Other versions or operating systems might not have dedicated wheels.

## Usage

```bash
uv run main.py
```
